# Hardhat-Deduction-System
AI-powered safety system that counts people on construction sites and checks hardhat compliance in real-time using YOLOv8


# 1. Python 3.11  
py -3.11 -m venv .venv

# 2. Activate
.venv\Scripts\activate

# 3. Pip upgrade  
python -m pip install --upgrade pip

# 4. Requirements install 
pip install -r requirements.txt

# 5. Run  
python app.py
